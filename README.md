# 축의금 접수·정산

모바일에서 축의금과 대인·소인 식권을 접수하고, 백업 파일을 맥북의 웹 브라우저로 옮겨 최종 명부를 정리하는 한국어 웹앱입니다.

## 개발

```sh
npm install
npm run dev -- --host 127.0.0.1 --port 5173
```

```sh
npm test
npm run build
```

## GitHub Pages 배포

GitHub Actions는 `main` 브랜치에 푸시될 때 앱을 빌드하고 GitHub Pages에 배포합니다. 저장소 설정의 **Pages**에서 빌드 및 배포 소스로 **GitHub Actions**를 선택하세요. 배포 주소는 `https://uk960214.github.io/wedding-ledger/`입니다.

프로덕션 빌드는 저장소 하위 경로(`/wedding-ledger/`)를 기준으로 정적 파일을 참조하며, 로컬 개발 서버는 루트 경로를 사용합니다.

접수 담당자에게는 [화면 캡처가 포함된 사용 가이드](https://uk960214.github.io/wedding-ledger/#/guide)를 전달하세요. 가이드는 장부를 만들지 않은 기기에서도 열리며, 앱의 시작 화면과 장부 관리에서도 새 탭으로 열 수 있습니다.

## 운영 원칙

- 신랑측과 신부측은 각 기기에서 독립 장부를 사용합니다.
- 데이터는 현재 브라우저의 IndexedDB에 저장됩니다. 앱 데이터 서버는 없습니다.
- 다른 기기나 다른 브라우저로 옮기려면 백업 파일을 저장하고 불러와야 합니다.
- 사이트 주소나 브라우저가 달라지면 기존 로컬 장부가 자동으로 보이지 않습니다.
- 백업 파일에는 이름과 금액 등 장부 내용이 포함됩니다.
- 번호는 취소·삭제해도 재사용하지 않습니다.

## 현재 단계

사용자에게 첫 UI를 확인받는 개발 단계입니다. PWA 오프라인 재실행과 iOS/Android 파일 공유 실기기 검증은 후속 단계입니다. 현장 사용 준비가 완료된 릴리스가 아닙니다.

확정 요구사항과 작업 경계는 [IMPLEMENTATION.md](./IMPLEMENTATION.md), 검증 기준은 [QA.md](./QA.md)에 기록합니다.
